</div>👨‍💻 Sobre mim
Olá! Sou Diego Borges, estudante de Engenharia de Software, com interesse em desenvolvimento web, soluções digitais e inteligência artificial.

Tenho experiência profissional em supervisão de segurança patrimonial, onde desenvolvi habilidades de liderança, organização e resolução de problemas. Atualmente, aplico essas competências à minha formação em tecnologia e à criação de projetos práticos.
🎯 Objetivo do projeto
Criar uma landing page responsiva, acessível e de navegação simples que funcione como portfólio acadêmico e vitrine profissional, permitindo que visitantes conheçam meus serviços e entrem em contato diretamente pelo WhatsApp.
✨ Funcionalidades
- Apresentação pessoal com fotografia original.
- Navegação por seções: Sobre, Serviços, Projetos e Contato.
- Layout responsivo para computadores e celulares.
- Menu mobile interativo com indicação de estado de abertura.
- Botões de contato via WhatsApp com mensagens pré-preenchidas.
- Links para GitHub e para o projeto SIGA PRO.
- Atualização automática do ano no rodapé.
🛠️ Tecnologias utilizadas
Tecnologia	Aplicação
HTML5	Estrutura semântica e conteúdo da página
CSS3	Estilização, Grid, Flexbox e media queries
JavaScript	Menu responsivo e ano automático no rodapé
GitHub	Versionamento e hospedagem do código-fonte
Vercel	Publicação da página na internet


Este portfólio é um site estático: não requer banco de dados, backend ou instalação de dependências.

🚀 Como executar localmente
1. Clone o repositório:
   git clone https://github.com/diegoborges-eng-soft/portfolio-diego-borges-Copiar.git
2. Abra a pasta do projeto:
   cd portfolio-diego-borges-Copiar
3. Abra o arquivo index.html no navegador. Se preferir, use a extensão Live Server no VS Code.
Não é necessário instalar Node.js ou executar comandos de build.
🌐 Site publicado
diego-borges-dev.vercel.app
